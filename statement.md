# Project Statement

## Objective

The objective of this project is to design a simple ATM (Automated Teller Machine) management system that performs basic banking operations from the command line interface.

## Problem Statement

Most of the small-scale projects require a basic banking system to demonstrate the working of transactions. This application provides a simple user interface through which an account holder can operate his account and witness the changes (in real-time) in the terminal.

## Scope of the Project

The application offers the following functionalities:

1. Login to the system using an account number and PIN
2. Check balance
3. Deposit money
4. Withdraw money
5. Transfer funds
6. Generate mini statement
7. View account holder's details
8. Change PIN
9. Account summary
## Functional Requirements
1. The application should take a valid account number and PIN from the user to authenticate each transaction.
2. The application should validate the PIN and account number.
3. The application should not allow withdrawal or transfer if the account balance is less than the amount to be withdrawn or transferred.
4. The application should store the transaction details for each account.
5. The application should have a menu-based system to perform various banking operations.
6. The application should display account summary with the total amount deposited and withdrawn.

## Assumptions

1. The account holder's details are stored in memory.
2. This project does not have any connection with the banking system.
3. This is a learning project, and no production-grade code is required.
4. This application only works in the terminal.

## Result

This project demonstrates a simple ATM banking system that works in the terminal using python programming language. The application is modular and can be used for learning purposes or as a guide to develop a similar application.
